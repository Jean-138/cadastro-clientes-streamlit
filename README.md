# Cadastro de Clientes com Streamlit

Este projeto é uma aplicação web simples feita com [Streamlit](https://streamlit.io/) que permite cadastrar clientes e salvar os dados em um arquivo CSV.

## Funcionalidades

- Cadastro de nome, endereço, data de nascimento e tipo de cliente (física ou jurídica)
- Salvamento automático em `clientes.csv`
- Interface simples e intuitiva

## Como rodar o projeto

1. Instale o Streamlit (caso ainda não tenha):
```bash
pip install -r requirements.txt

streamlit run main.py
